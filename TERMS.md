- Full backup **export** (download) of bookmarks metadata needed for restore, notes, guide images, and panel preferences (as implemented in the current extension version).  
- Full backup **import** / restore with URL matching options.

Core BookmarkMemo features (floating panel, notes, guide images, capture & annotate, folder edit tools, etc.) remain **free**.

Buy Me a Coffee / tips do **not** unlock Pro.

### 2. Local product; online checks for abuse control
Pro authorizes **local use** of the unlocked features on your device.

Online license activation / validation (via Lemon Squeezy) is used mainly to:

- confirm a key is valid;  
- enforce the **device activation limit** (currently **2** devices);  
- reduce abuse (key sharing beyond the limit, obvious fraud).

Bookmark contents, notes, and guide images are **not** sent to Lemon Squeezy or to a developer server for licensing.

### 3. Offline use after validation; service discontinuation
After a successful activation (or a successful validation) on a device, the extension stores a local license state.

- If the license servers are **temporarily unreachable**, a previously activated device may continue to use unlocked Pro features using that **local license state** (offline continuation).  
- If licensing / checkout services are **permanently discontinued** or can no longer validate keys, **already activated** devices may keep using unlocked Pro features via the stored local license state, for the features that remain available in the installed extension build.  
- This does **not** require the developer to run servers forever, host Chrome Web Store listings forever, or ship updates forever.

New activations may become impossible if checkout or license APIs stop. Keep your License Key and export backups while you can.

### 4. Chrome, Web Store, and future changes (no warranty of perpetual compatibility)
BookmarkMemo runs as a Chrome extension and depends on Google Chrome, Chromium APIs, and (if installed from there) the Chrome Web Store.

Without limiting other disclaimers:

- Chrome, OS, or Web Store **policy or API changes** may break, limit, or remove features.  
- The developer may change free/Pro scope, UI, or behavior in **future versions**; a one-time purchase does **not** guarantee every future feature. Pro’s paid scope is **backup export/import** as described at purchase time unless a future version states otherwise.  
- Listings may be removed; updates may stop. You may keep using an already installed build subject to Chrome still allowing it.  
- The software is provided **as available**. There is **no** guarantee of uninterrupted service, fitness for a particular purpose, or that Pro will work on every device forever.

### 5. Devices, transfers, refunds
- Device limit: see store listing / product page (currently **2**).  
- Moving to a new device may require activating with your License Key within that limit (and Lemon Squeezy’s rules for deactivating instances, if any).

### 6. Your responsibilities
